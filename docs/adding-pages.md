# 페이지 추가하기 (개발 경험 없어도 됩니다)

**반오토(BahnAuto)** 서비스 홈페이지에 새 페이지를 올리는 방법입니다.

git이나 터미널 없이, **GitHub 웹사이트에서만** 페이지를 추가할 수 있습니다.
브라우저에서 파일을 올리면 검사와 배포는 자동으로 돌아갑니다.

---

## 먼저 알아둘 것

**0. 이 사이트는 '반오토' 서비스 홈페이지입니다.**

운영사는 (주)우리끼리지만, **화면에 보이는 브랜드는 '반오토'** 입니다.
페이지를 만들 때 회사 이름이 아니라 서비스 이름을 쓰세요.
운영사 표기는 푸터에만 들어가며, 템플릿에 이미 들어 있으니 그대로 두면 됩니다.


**1. 파일 이름이 곧 주소입니다.**

```
faq.html     →  https://bahnauto.kr/faq
notice.html  →  https://bahnauto.kr/notice
```

그래서 파일 이름은 **영문 소문자·숫자·하이픈(-)만** 씁니다.
`자주 묻는 질문.html` 처럼 한글이나 공백이 들어가면 주소가 깨집니다.

| 이렇게 | 이러지 말고 |
|---|---|
| `faq.html` | `자주 묻는 질문.html` |
| `price-guide.html` | `Price Guide.html` |
| `notice.html` | `공지사항.html` |

**2. 저장할 때 인코딩은 UTF-8 입니다.**

메모장에서 저장할 때 `[다른 이름으로 저장]` → 아래 **인코딩**을 **UTF-8** 로 선택하세요.
`ANSI` 로 저장하면 사이트에서 한글이 전부 깨집니다.

**3. `main` 에 직접 올릴 수 없습니다.**

올린 내용은 **검토를 거쳐** 사이트에 반영됩니다. 아래 절차에 그 과정이 들어있습니다.
실수해도 사이트가 망가지지 않는다는 뜻이니 안심하고 올리세요.

---

## 1단계 — 템플릿 복사하기

빈 화면부터 시작하지 마세요. [`docs/page-template.html`](page-template.html) 을 복사해서 쓰면
헤더·푸터·글꼴·색상이 기존 페이지와 자동으로 맞춰집니다.

1. GitHub에서 [`docs/page-template.html`](https://github.com/uriggiri-inc/bahnauto/blob/main/docs/page-template.html) 을 엽니다
2. 우측 상단 **`Raw`** 버튼 → 전체 선택(`Ctrl+A`) → 복사(`Ctrl+C`)
3. 메모장이나 VS Code에 붙여넣고, 원하는 이름으로 저장 (예: `faq.html`)
   - **저장할 때 인코딩 UTF-8 확인**

템플릿 안에 이런 표시가 있습니다.

```html
<!-- ▼▼▼ 여기 4곳만 페이지에 맞게 바꿔주세요 ▼▼▼ -->
```

제목, 설명, 주소 4곳만 바꾸고 나머지는 그대로 두세요.
본문은 `<!-- ▼ 본문 -->` 부터 `<!-- ▲ 본문 끝 -->` 사이를 고치면 됩니다.

## 2단계 — GitHub에 올리기

1. https://github.com/uriggiri-inc/bahnauto 접속
2. **`Add file`** → **`Upload files`** 클릭
3. 만든 `.html` 파일을 드래그해서 올립니다
   - 이미지도 함께 쓴다면 `assets/` 폴더로 들어가서 따로 올려주세요
4. 아래로 내려가서 **커밋 메시지**를 씁니다
   ```
   자주 묻는 질문 페이지 추가
   ```
5. 그 아래 **`Create a new branch for this commit and start a pull request`** 를 선택합니다
   > ⚠️ 위쪽 `Commit directly to the main branch` 는 선택할 수 없습니다. 아래쪽을 고르세요.
6. **`Propose changes`** 클릭
7. 다음 화면에서 **`Create pull request`** 클릭

여기까지 하면 끝입니다.

## 3단계 — 자동 검사 결과 확인

PR 화면 아래쪽에 검사 결과가 나타납니다. 1분 정도 걸립니다.

**초록색 체크 ✅** — 문제 없습니다. 검토자에게 알리고 기다리시면 됩니다.

**빨간색 X ❌** — 고칠 것이 있습니다. `Details` 를 누르면 이렇게 나옵니다.

```
  [faq.html]
    문제: charset 선언이 없습니다
    해결: <head> 안 맨 위에 <meta charset="UTF-8"> 을 넣어주세요.
          없으면 한글이 깨질 수 있습니다.
```

**문제와 해결 방법이 한국어로 같이 나옵니다.** 그대로 고쳐서 다시 올리면 됩니다.
같은 PR 화면에서 파일을 다시 올리면 검사가 자동으로 다시 돕니다.

잘 모르겠으면 **PR 화면 아래 댓글로 물어보세요.** 캡처를 붙여주시면 더 좋습니다.

## 4단계 — 검토 후 반영

검토자가 확인하고 **Approve** 하면 병합할 수 있게 됩니다.
**`Squash and merge`** 버튼을 누르면 **1분 안에** https://bahnauto.kr 에 올라갑니다.

주소가 바로 보이지 않으면 `Ctrl+F5` (Mac은 `Cmd+Shift+R`) 로 새로고침해보세요.

## 메뉴에 새 페이지 넣기

새 페이지를 만들어도 **상단 메뉴에는 자동으로 안 뜹니다.** 메뉴에 넣으려면
`index.html`, `about.html`, `service.html`, `contact.html`, `404.html`,
그리고 새로 만든 페이지까지 **전부** 아래 두 곳을 똑같이 고쳐야 합니다.

```html
<!-- 상단 메뉴 -->
<nav class="nav" aria-label="주요 메뉴">
  <a href="/about">서비스 소개</a>
  <a href="/service">이용 안내</a>
  <a href="/faq">자주 묻는 질문</a>   ← 이 줄 추가
  <a href="/contact">문의</a>
</nav>

<!-- 아래쪽 푸터 메뉴 -->
<nav class="footer-nav" aria-label="푸터 메뉴">
  <a href="/about">서비스 소개</a>
  <a href="/service">이용 안내</a>
  <a href="/faq">자주 묻는 질문</a>   ← 이 줄 추가
  <a href="/contact">문의</a>
</nav>
```

`sitemap.xml` 에도 아래 내용을 추가해주세요. 검색엔진이 새 페이지를 찾는 데 씁니다.

```xml
  <url>
    <loc>https://bahnauto.kr/faq</loc>
    <changefreq>monthly</changefreq>
    <priority>0.7</priority>
  </url>
```

> 파일마다 메뉴를 복사해두는 게 번거로운 건 맞습니다. 순수 HTML의 한계입니다.
> 페이지가 6~7개를 넘어가면 개발 담당자에게 정적 사이트 생성기 도입을 요청하세요.
> 그때부터는 메뉴를 한 곳에서만 고치면 됩니다.

## 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| 한글이 `���` 로 깨짐 | ANSI로 저장 | 메모장 → 다른 이름으로 저장 → 인코딩 **UTF-8** |
| 페이지는 뜨는데 디자인이 없음 | `<link rel="stylesheet" href="/assets/style.css">` 를 지움 | 템플릿의 `<head>` 부분을 그대로 복사 |
| 이미지가 안 보임 | 파일을 `assets/` 에 안 올렸거나 이름 철자가 다름 | 대소문자까지 정확히 맞춰주세요 (`Photo.jpg` ≠ `photo.jpg`) |
| 주소가 404 | 파일 이름에 한글·공백이 있음 | 영문 소문자와 하이픈으로 바꿔주세요 |
| 메뉴에 새 페이지가 안 뜸 | 메뉴는 자동이 아님 | 위 "메뉴에 새 페이지 넣기" 참고 |
| 올렸는데 사이트에 없음 | PR이 아직 병합되지 않음 | 검토자 승인 후 `Squash and merge` 필요 |

## 절대 건드리면 안 되는 파일

| 파일 | 지우면 |
|---|---|
| `CNAME` | `bahnauto.kr` 주소가 끊깁니다 |
| `.nojekyll` | 일부 페이지가 404가 됩니다 |
| `404.html` | 없는 주소로 들어왔을 때 안내 페이지가 사라집니다 |
| `assets/style.css` | 전체 사이트 디자인이 사라집니다 |

자동 검사가 이 파일들을 지웠는지도 확인하므로, 실수로 지우면 병합 전에 막힙니다.

## 미리 보고 싶다면

올리기 전에 내 컴퓨터에서 확인하는 방법입니다. **선택 사항**이고, 안 해도 됩니다.

파일을 더블클릭해서 열면 디자인이 깨져 보입니다. 정상입니다 —
`/assets/style.css` 같은 주소는 서버에서만 동작하기 때문입니다.

제대로 보려면 저장소 폴더에서 아래 명령을 실행하고 http://localhost:8000 에 접속하세요.

```bash
python3 serve.py
```
